M2iBank - Digital Core Banking System

DigiBank

Digital Core Banking System for M2iBank

Project Overview

DigiBank is a modular monolithic banking application developed as part of the DevSecOps workshop. It provides core services for customer management, account management and bank transfers.

Available Functional Domains

  • Customer registration and consultation.
  • Account creation and account listing by customer.
  • Transfer execution between accounts.
  • Transfer history consultation for a specific account.

API Documentation

The REST API documentation is available through Swagger/OpenAPI.
